# The runner's toolbox, pinned. Same manifest + same architecture => the
# same bytes, so the image's SHA-256 names exactly one root file system.
#
# One `key value...` per line; `#` starts a comment. `build.sh` reads it.
#
# suite      — the Debian release the root is built from
# snapshot   — the snapshot.debian.org timestamp every archive is fetched at
# archive    — `<archive> <suite>`: one snapshot.debian.org archive and suite,
#              all at `snapshot`, so updates and security fixes are pinned too
# uuid       — the file-system UUID, fixed so it never varies between builds
# erofs      — mkfs.erofs's compressor, level and block size, pinned so a
#              builder's page size or a newer default cannot change the
#              image; the features it ends up with go in the release manifest
# packages   — installed on top of the minimal base
# vendor     — `<dpkg-arch> <url> <sha256> <member>=<name>...`: a binary
#              Debian does not ship, fetched by URL, refused unless its
#              SHA-256 matches, each member installed as /usr/local/bin/<name>
