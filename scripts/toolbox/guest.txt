# What a Firecracker microVM boots from, pinned. Same manifest + same
# architecture + same builder => the same bytes for the monitor, the jailer
# and the guest kernel; the initramfs adds only the runner binary it is given.
#
# One `key value...` per line; `#` starts a comment. `guest.sh` reads it.
#
# epoch    — seconds since 1970 stamped into the kernel's banner and onto the
#            initramfs's one file, fixed so neither varies between builds
# kernel   — `<version> <url> <sha256>`: the kernel.org source tarball, refused
#            unless its SHA-256 matches the one kernel.org signs in
#            sha256sums.asc
# config   — `<dpkg-arch> <url> <sha256>`: the configuration Firecracker's own
#            Continuous Integration (CI) builds and boots this kernel version
#            with; the path names the CI run's date and Firecracker commit.
#            `guest.config` is merged over it
# monitor  — `<dpkg-arch> <version> <url> <sha256> <member>=<name>...`: the
#            Firecracker release archive, refused unless its SHA-256 matches
#            the release's own `.sha256.txt`; each member is installed as
#            <name>
