DESCRIPTION
  agentsfleet cli

USAGE
  agentsfleet <subcommand> [flags]

FLAGS
  --api <url>    API base URL
  --json         Machine-readable JSON output

GLOBAL FLAGS
  --help, -h
      Show help information
  --version, -v
      Show version information
  --wizard
      Start wizard mode for a command
  --completions <bash|zsh|fish|sh>
      Print shell completion script (choices: bash, zsh, fish, sh)
  --log-level <all|trace|debug|info|warn|warning|error|fatal|none>
      Sets the minimum log level (choices: all, trace, debug, info, warn,
      warning, error, fatal, none)

SUBCOMMANDS
  login        Authenticate via browser
  logout       Sign out — revoke this machine's credential, abort unfinished
               sign-ins, and clear local state (other machines stay signed in)
  whoami       Show who this terminal is signed in as
  auth         Inspect authentication state
  doctor       Diagnose CLI configuration and connectivity
  workspace    Manage workspaces
  grant        Manage integration grants
  api-key      Manage tenant API keys
  connector    Inspect workspace connectors
  approvals    Review and decide pending approval gates
  tenant       Tenant-scoped commands
  billing      Tenant billing dashboard
  library      Browse this workspace's Fleet library gallery
  models       List the model catalogue this server serves
  install      Install a Fleet from a library entry (--library <library_id>)
  fleet        Fleet management subcommands
  list         List fleets in the active workspace (paginated)
  status       Show status for every fleet in the active workspace
  stop         Halt the running session (resumable)
  resume       Resume from stopped or auto-paused
  kill         Mark terminal (irreversible)
  delete       Hard-delete a killed fleet
  logs         Tail fleet activity
  events       Page through historical events
  steer        Send a message; stream the response
  secret       Workspace secret vault
  schedule     Manage hosted Fleet schedules
  memory       Inspect a Fleet's durable memory (read-only)
Environment variables: https://docs.agentsfleet.net/cli/configuration
