DESCRIPTION
  agentsfleet cli

USAGE
  agentsfleet <subcommand> [flags]

FLAGS
  --api <url>    API base URL
  --json         Machine-readable JSON output

GLOBAL FLAGS
  --help, -h
      Show help information
  --version, -v
      Show version information
  --log-level <all|trace|debug|info|warn|warning|error|fatal|none>
      Sets the minimum log level (choices: all, trace, debug, info, warn,
      warning, error, fatal, none)

SUBCOMMANDS
  login          Authenticate via browser
  logout         Sign out — revoke this machine's credential, abort unfinished
                 sign-ins, and clear local state (other machines stay signed in)
  whoami         Show who this terminal is signed in as
  doctor         Diagnose CLI configuration and connectivity
  workspace      Manage workspaces
  chat           Create, resume, and review a private workspace chat
  fleet          Run, steer and inspect fleets
  library        Browse this workspace's Fleet library gallery
  models         Browse the model catalogue and choose the tenant's provider
  secrets        Workspace secret vault
  connections    Inspect workspace connectors
  api-keys       Manage tenant API keys
  usage          Balance and recent spend for this tenant
  platform       Administer platform resources with your existing operator
                 scopes
Environment variables: https://docs.agentsfleet.net/cli/configuration
