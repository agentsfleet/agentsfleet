# Schema usage and design audit : Sep 18, 2026

**FAIL.** Runtime table orphans, missing repair writers and unused SQL remain. Static review also found one delivery-index mismatch and one recovery fairness defect. This design cannot receive an optimality PASS without workload measurements.

Scope: every `schema/*.sql` file in this checkout, in registered migration order; executable query definitions and their callers; table constraints, explicit indexes, grants and triggers. Primary key (PK) and foreign key (FK) abbreviations are used below. PASS means a production-source consumer or necessary schema role was found and no confirmed defect was identified in this audit; it does not certify a measured optimal query plan. FAIL identifies a concrete finding requiring an ownership or implementation remedy.

The audit inspected this checkout at commit `c6b54a1a5365b28d3d35ebc3d0384b6920b3f469`. Pre-existing and concurrent `afd_wire` edits were left untouched. The source review did not pin a separate immutable checkout. No SQL, application code, migration registrations or database contents were changed. No repository test gate, live data inspection or EXPLAIN was run.

Inventory: **55 SQL files; 55 registered migrations; 38 tables; 53 FK declarations; 58 explicit index declarations, of which 57 survive all migrations.** Slot 912 intentionally drops the cleanup index introduced in slot 835. PK/UNIQUE-backed implicit indexes are included in constraint review, but are not part of the explicit-index count.
