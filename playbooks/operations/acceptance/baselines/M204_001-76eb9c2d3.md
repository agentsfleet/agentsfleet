## How the delta was counted, and why it is trustworthy

Two independent methods agree, which is the point of running both.

**Per file, against the comparison revision.** For every `*.rs` in
`git diff --name-only 76eb9c2d3...HEAD`, count `#[test]`, `#[tokio::test]` and
`#[ignore]` in the working tree and in `git show 76eb9c2d3:<path>`, and sum the
differences:

| File | `#[test]` | `#[tokio::test]` | `#[ignore]` |
|---|---|---|---|
| `afd_api/tests/fleet_lifecycle_live/library_removal.rs` | +0 | +3 | +3 |
| `afd_api/tests/integration_workspace_library_entries.rs` | +0 | +5 | +5 |
| `afd_api_tenant/src/handler/library_entry/remove.rs` | +2 | +0 | +0 |
| `afd_api_tenant/src/handler/library_entry/tests.rs` | +8 | +0 | +0 |
| `afd_db/tests/migration_slot_grants.rs` | +2 | +0 | +0 |
| `afd_library/src/catalogue/entries.rs` | +1 | +0 | +0 |
| `afd_library/src/catalogue/entries/sql.rs` | +6 | +0 | +0 |
| `afd_library/tests/integration_catalogue/entry_privileges.rs` | +0 | +1 | +1 |
| `afd_wire/src/workspace_library.rs` | +3 | +0 | +0 |
| **Total** | **+22** | **+9** | **+9** |

Every `#[tokio::test]` this diff adds is `#[ignore]`d, so all nine are
integration and none of them inflates the unit figure.

**Repo-wide, at both revisions.** `git grep -c` for the same three attributes
at `76eb9c2d3` and at HEAD: `test` 2076 → 2098, `tokio::test` 788 → 797,
`ignore` 578 → 587. Deltas +22, +9, +9 — the same answer from a different
direction. The absolute totals here are larger than the runtime counts because
a static grep cannot see which tests a `cfg` gate excludes or a macro
generates; only the delta is claimed.

**A first pass read +10 and was wrong.** `git grep -E` is POSIX ERE and does
not know `\s`, so `^\s*#\[test\]$` silently matched only unindented
attributes. `[[:space:]]*` is the fix, and the disagreement with the per-file
count is what surfaced it.

## Cross-check

The derived integration figure of 561 is exactly the branch figure
`M203_001` recorded for itself, and M203 merged into `main` before this
comparison revision. Two independently derived numbers landing on the same
value is the strongest evidence available without a build.

The Rust unit figure does not cross-check as cleanly: M203_001 recorded
`unit 2648 Rust` for its branch, where this derivation gives 2640 for a later
revision. That difference of eight is **unreconciled**. It was measured on a
different revision by a different run, and settling it needs a build at the
comparison revision — the thing the disk will not allow. Flagged rather than
explained away.
