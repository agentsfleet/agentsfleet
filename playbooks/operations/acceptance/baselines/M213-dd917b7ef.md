## Delta

- **Rust unit, runner shard: 1171 → 1248, +77, both on Linux.** The tests this
  branch adds: the egress scope, its netlink transport and the sandbox network
  (M213_002), the `apply_patch` read cap (M213_001 §7, 4 tests), and the
  refusal of a fleet egress host at a private address (M213_002 Dimension 2.8,
  3 tests). The macOS figure, 1178, leaves out the Linux-only egress module.
- **Rust unit, daemon shards: daemon 132 → 131, daemon libraries 3138 → 3139.**
  One signal-handling test moved with the code, from `agentsfleetd` to
  `afd_core`. These two shards were measured on macOS against Linux.
- **TypeScript: app 3642 → 3648, +6.** `fleetFailureCopy.test.ts` runs one
  test per runner refusal line, and the list grows from 6 lines to 12. **CLI
  1777 → 1778 passed and 17 → 16 skipped:** one test skips in CI's
  environment and runs on macOS; no CLI test changed on this branch.
- **Rust integration: not compared locally.** The baseline's 5203 is counted
  through the coverage shards, which run every test with the ignored ones
  included; the local `make test-integration-rustd` runs the ignored suite
  alone. The branch's own CI runs the same shards, and its count is the
  like-for-like figure.
