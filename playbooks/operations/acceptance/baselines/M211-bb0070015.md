## Delta

- **Rust unit: 4212 → 4312, +100 passed; ignored 879 → 895, +16.** The
  baseline ran on Linux and the branch on macOS, where the Linux-only sandbox
  tests do not compile, so +100 is a floor; the branch's own CI run is the
  like-for-like figure. The added tests cover nested loops (M211_002), the
  executor's shell-reported kills (M211_003), the hold registry and keeper
  (M211_004) and the finished-turn history read (M211_005). The 16 newly
  ignored tests are live-datastore integration tests, which run only in the
  integration lane.
- **TypeScript: unchanged except the CLI, 1779 → 1778 passed and 17 → 16
  skipped.** `900ee9e1d` drops the tests that grade the repository's own
  manifests (M215_001, a deliberate cut).
- **Rust integration: not compared locally.** The baseline's 4929 is counted
  through the coverage shards, which run every test with the ignored ones
  included; the local `make test-integration-rustd` runs the ignored suite
  alone. The branch's own CI runs the same shards, and its count is the
  like-for-like figure.
