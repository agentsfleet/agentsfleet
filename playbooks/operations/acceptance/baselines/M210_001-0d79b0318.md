(`git worktree add --detach ../agentsfleet-baseline-0d79b0318 0d79b0318`), with
its own compose project, so its datastores were never the branch's. The cargo

the disk could not hold two; the cache holds build outputs only, and cargo
rebuilds whatever differs between the revisions. Builds used
`CARGO_PROFILE_DEV_DEBUG=line-tables-only CARGO_INCREMENTAL=0` for the same
reason; neither changes what a test does.
