# M237_002 sandbox start: before and after the socket pair and the in-process disk

Branch: `feat/m237-sandbox-lease-path`.
Comparison revision: `937c8d34d`, the M237_001 baseline, whose engine is `2f8c878c0`'s.
Indy asked on Nov 02, 2026 for the measurement to run locally through the make targets, not on the dev host.

## Where the figures come from

| Source | Host | Kernel | What it measures |
|---|---|---|---|
| `make test-runner-kernel`, `test_start_budgets_with_four_leases` | OrbStack machine `afr-kernel`, Debian 13.7 | `7.2.12-orbstack-00394-gbecdd6130068` | Real `BubblewrapEngine` starts: executor-ready and first command, 100 leases, 4 at once |

The OrbStack lane runs OrbStack's kernel, not Debian's `6.12`, so its figures size the change rather than predict the dev host's.
Every column ran on the same machine, the same toolbox and the same trial.

## Executor ready

| Cache | Before p50 | p95 | p99 | After p50 | p95 | p99 |
|---|---|---|---|---|---|---|
| cold | 100.8 ms | 321.6 ms | 442.7 ms | 42.3 ms | 54.5 ms | 107.9 ms |

Before is `937c8d34d`. After is `c24c4b481`, the engine this Pull Request ships, with the toolbox buffered.

Two runs between them show which change moved the figures:

| Revision | What it had | Cold p50 / p95 / p99 | Warm p50 / p95 / p99 |
|---|---|---|---|
| `beeacb8b0` | the in-process disk, no socket pair | 37.7 / 49.4 / 51.8 ms | 32.2 / 41.4 / 57.9 ms |
| `e7c03a27d` | the socket pair and a direct-I/O toolbox | 42.1 / 57.4 / 59.4 ms | 30.8 / 39.7 / 43.3 ms |

The drop is the in-process disk: every p50 after it sits between 30 and 43 ms. Each column is one run of 100 leases, so a p99 is one lease's figure, not a measured slow-down. The socket pair's gain is the removed poll and socket directory, not a measured speed-up.

## What changed between the columns

| Step | Before | After |
|---|---|---|
| Workspace disk | `mount -o loop`, a host program, then `LOOP_SET_DIRECT_IO` | `LOOP_CONFIGURE` with direct I/O and `mount(2)`, in-process on the blocking pool |
| Toolbox device | buffered | buffered; direct I/O was built, measured against first use and reverted (M237_002 Discovery) |
| Executor ready | `connect` retried every 10 ms on a bound socket file | one listing over an inherited socket pair, nothing polled |
