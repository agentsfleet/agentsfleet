## The integration lane's one retry

The first final integration run failed on
`afd_bench::lanes_cardinality::test_cardinality_bench_reports_memory_per_fleet_across_the_ladder`
(`every rung costs memory per fleet`, `lanes_cardinality.rs:43`): the bench
reads live Redis `used_memory` per rung, and one rung reported no growth.
The test is untouched by this branch, was green at the baseline, and passed on
the immediate rerun; `cargo test` stops at the first failing binary, so the
first run's 126 passed is not a partial verdict on the rest. Recorded as a
flake of a memory-sampling bench, not a regression.
