in each checkout and its summary line read directly, rather than inferring the
baseline from the final run.

The Rust and integration rows are marked unchanged rather than re-measured, on
one checkable fact: this diff contains no `.rs` file.

```
git diff --name-only origin/main...HEAD | grep -c '\.rs$'   # 0
```

That is the whole justification for those two rows. If a later revision of this
branch adds Rust, both must be re-measured.
