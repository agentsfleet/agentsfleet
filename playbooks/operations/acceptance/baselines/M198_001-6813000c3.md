## Why the TypeScript baseline is absent

`make test-unit-all` on the baseline worktree exits 127 on `vitest: command not
found`. That worktree never had the per-package `bun install` a fresh linked
worktree needs — the trap `CLAUDE.md` documents, not a defect in the tree. The
Rust half of that same run completed green, which is the half this comparison
uses. The branch changes no `ui/**` file, so the TypeScript count is not a
number this diff can move; the final figure is recorded above for completeness.

## Where the deltas come from

The +18 unit tests are the resume state's own proofs and the counter's
datastore-free cases: `reconcile/progress/tests.rs` carries the rotation, wrap,
capacity, refile and deleted-cursor cases, `sweep/reconcile/tests.rs` the
hand-off and poisoned-state cases, `openapi_contract.rs` the ingress
description, and `integration_attempt_count.rs` contributes
`bookkeeping_failure_does_not_discard_an_answer`, which runs a fake ledger and
needs no datastore despite living in a `tests/` suite.

The +19 integration tests are the boundary reproductions that need both live
datastores: the two starvation boundaries, the deleted-fleet cursor case, the
concurrency and outage cases, the delivery-lookup pair, and the seven counter
cases that drive a real outbound harness.

## Three lane failures, none a regression

- **`CopyButton.test.tsx:71`** (TypeScript, `design-system`) — one failure,
  `expected '' to match /copy failed/i`, then 631 of 631 passing on re-run. The
  test awaits `findByRole("status")` and reads `textContent` before the live
  region fills. This branch touches no file in that package; fixing it is
  outside this spec's Files Changed scope and is reported as open.
- **`afd_dragonfly` `integration_ready::test_ready_index_read_surface`** — one
  failure, "a marked fleet must be sampled from its own partition", then `ok`
  on re-run through the same target. This branch changes no file under
  `afd_dragonfly`, and the baseline lane at `6813000c3` passed the same suite.
- **`afd_dragonfly` `integration_capacity`, `WRONGTYPE` on `XLEN`** — not a
  flake and not the tree's fault. That run set `KEEP_TEST_STATE=1`, which skips
  the per-run datastore reset, so a previous run's keys were still there. The
  inner-loop knob is not safe across suites that rebuild stream data.
